# ギア指令Stuck-atの予備実験

## 対象と条件

`Transmission/TransmissionRatio/gear` → ギア比Look-Up TableへFIM `Stuck-at` を挿入する。
任意のギア値の設定ではなく、故障直前の値を保持する。
開始5・10・15秒 × 継続0.2・0.5・1秒の全9条件を故障シミュレーション前に固定する。
入力ごとの変速時刻に合わせた開始時刻の調整はしない。
ギア比表は `[1 2 3 4] → [2.393 1.450 1.000 0.677]`。

固定130入力を正常＋9故障で実行（1300波形）。`fixed_input_design.py` に全選定規則を記載。
定値60/80/100、60→100、100→60、80→100→80の6例、60/100の全64組合せ、
6次元LHS64本（seed20260926）から重複4本を除く。
各入力は5秒ごとのアクセル6値（60–100%）・ブレーキ0。
要件は本実験と同じ `F[0,20](speed >= 95)` と、30秒のギア離散性。

## ネイティブFIMと補正

FISingle/FCSingleで挿入・設定し、生成CSVと `fault_table` を保存する。
上流のMemory/Switch回路は維持する。
上流マスク初期化はインスタンスでなくライブラリの固定パスを書き換える。
さらに実ライブラリのPulse Generatorは「サンプルベース・1秒刻み」で、0.2秒等を整数パラメータに設定できない。
[MathWorksの仕様](https://www.mathworks.com/help/simulink/slref/pulsegenerator.html)に従い、
0.01秒刻み・サンプルベースを明示し、幅/開始/周期をサンプル数へ変換する。
例えば0.2秒は20サンプル。周期50000サンプル＝500秒で、30秒間に故障窓は一度だけ。

`fim_configure_stuck.m` が対象インスタンスへ設定する。改行入りの内部ブロック名は型検索で解決。
`fim-stuck-duration.patch` は実験コピーのFCSingleにだけ適用し、元依存は変更しない。

## 検証・読み方

1. 単体18件: 各窓内で入力を2→3に変え、固定・解除・無効化を厳密照合。
2. ATの指令ギア・適用ギア・実ギア比・故障ゲートを保存し、保持値/期間/解除を照合。
3. 正常・指令・適用ギアはいずれも1・2・3・4。値を丸めたり範囲に押し込めたりしない。
4. 各故障の代表6入力で無効化→正常一致を確認。違反入力は有効再実行・無効化も確認。
5. CSVをPythonで独立監査し、保持動作・ギア比・要件余裕・集計を再計算する。

元ATの指令ギアと正常ギア比は0.04秒周期で記録される。生の時刻と値は各MATへ残し、
比較CSVの0.01秒軸には直前値の保持で揃える。ギア値の線形補間や丸めはしない。

`summary.csv` の `InputsWithHeldShift` は指令と適用ギアが異なった入力数、`Violations` は加速要件の違反数。
故障が変速を妨げても加速要件に違反するとは限らない。
`fixed/results.csv` は1300件の結果、`fixed-inputs.csv` は全130入力、`fixed/traces` は全波形。
反例探索/学習はしないため、ツールの優劣や全入力の安全性は主張しない。
