# トルク比5条件の本実験（2026-09-26）

## 固定条件

注入箇所: `Transmission/TorqueConverter/TorqueRatio` → `Turbine` 第2入力。
FIM `Bias/Offset` で、5秒以降の比率を固定量だけ減算する（百分率ではない）。
IDは対応を保つ: T01=−0.02、T04=−0.03、T05=−0.04、T02=−0.05、T03=−0.10。

30秒、5秒ごとのアクセル6値（60–100%）、ブレーキ0、同じ初期状態、ode5/0.01秒。
加速要件は「開始から20秒までに一度は95 mph（約153 km/h）に到達」:
`F[0,20](speed >= 95)`。平均車速や毎秒の加速度の要件ではない。
探索指標 `(20秒までの最高車速−95)/80` は負なら違反、0は満足。
ギアは全ログ時刻で厳密に1・2・3・4。離散性の異常は整合性エラーとして停止する。
元ARCHモデルを使うが、加速要件と入力範囲は研究用の設定で、公式ARCH2025要件ではない。
正常128入力の確認は有限検査であり全入力の安全性証明ではない。

## 学習・予算・公平性

5手法各100独立試行×5故障＝2500試行。各1500入力まで、LHS・初期経験収集も含む。
seedは390001–390100。各試行は新規プロセス・新規学習状態、故障・seed間に持ち越さない。
seedごとに25条件の順序を固定乱数でシャッフルし、単一ワーカーで実行する。
同じ入力を与えるのでなく、手法が選べる範囲・時間刻みを共通化する。

- A3C: 5行動ステップまたはエピソード終了で更新。
- ACER: オンライン更新に加えて経験再生。容量を上流の10から10000遷移に補正し、再生開始50を維持。
- DDQN: 経験500遷移から更新（500入力ではない）。1入力6行動・6遷移。対象ネットワーク更新間隔100。
- Ψ-TaLiRo: 最初の100入力はLHS。その後固定版ConBOの単一要件EI経路、CPU版GP接続で探索。
  ARCHの複数要件除去型探索や公開スコアの完全再現ではない。
- RAND: 学習せず、同じ許容範囲から選ぶ比較基準。

途中の報酬0、6番目の行動後の終端報酬 `exp(-rho)-1`。
Falsifyは途中の状態を観測して次のアクセルを選ぶ。Ψ-TaLiRoは6値の波形全体を選ぶ。
アルゴリズム単体でなく接続を含む探索ツールの比較である。
実更新数を記録し、学習前の成功を学習効果と解釈しない。

## 停止と測定

最初の負の指標について保存入力を故障モデルで再実行し、同じ入力で正常モデルが満足すれば成功。
未発見は1500入力で打切り。NaN・ギア異常・正常違反・再現不一致・プロセス失敗はエラーとし、成功/未発見に数えない。
独立再検証の時間は探索時間と分け、最初の候補でも接続一致を検査する。

中心指標: 故障別発見率、発見までの入力数、探索実時間。
100・500・1500本以内の発見率を併記し、未発見も残す。成功だけの平均で優劣を決めない。
100 seedsは各条件の独立試行であり、手法間の同一入力は保証しない。
旧試行・Stuck-at予備実験・smokeは本実験の100試行に流用しない。
−0.02で反例が存在するかは未確認でも、指定された5条件は固定して残す。

`protocol.json`/`fault_catalog.csv`: 実条件。`generation_*/Configuration/enable.csv`: FIM設定。
