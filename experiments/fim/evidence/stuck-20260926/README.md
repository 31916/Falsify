# Stuck-at予備実験の結果（2026-09-26）

## 結論

正常＋9故障条件×固定130入力＝1300波形の検証を完了した。
全9条件で実際のギア固定を確認したが、加速要件 `F[0,20](speed >= 95)` の違反は各0/130だった。
「故障が挿入されていない」という結果ではない。また、全入力で違反しないという証明でもない。
今回の短い固定時間を、そのまま有効な反例がある性能比較ケースとして採用できる根拠はまだない。
将来は固定時間の拡大などを別の予備実験で検討する。本実験の条件を事後変更しない。

## 故障が動作した具体例: S03 / I121

図示・確認用に、指令と適用ギアが異なる時間が最長の例を保存した（性能評価のためのケース選別ではない）。
5秒で3速指令が出るが、実ギアは2速に固定され、6秒に3速へ復帰する。
95 mph到達は正常14.71秒→故障15.54秒と0.83秒遅れるが、20秒以内なので要件は満たす。
20秒までの最高車速は正常109.0373 mph→故障106.9908 mph。

アクセル6値（0・5・10・15・20・25秒）は
`[66.80106059, 67.03798059, 78.61660628, 85.05396942, 63.70220212, 75.38670708]`%、ブレーキ0。
完全精度の値は `fixed-inputs.csv` のI121にある。
比較波形は `traces/B00_I121.csv` と `traces/S03_I121.csv`。
